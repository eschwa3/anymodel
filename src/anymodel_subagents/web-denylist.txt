# Bundled web denylist (docs/adr/0001-worker-web-access.md, "Portable launch
# denylist"). Format is documented in web_denylist.py's module docstring --
# that docstring is the spec; this file just fills it in.
#
# Scope: known exfiltration sinks only -- services whose entire purpose is to
# catch, relay, or anonymously host attacker-controlled traffic. No
# general-purpose platforms (no github.com, no google.com): where a sink is a
# feature of a broader platform, only that feature's own subdomain is listed.
# This is a speed bump, not a boundary -- an attacker can always register a
# fresh domain (see the ADR's security analysis).
